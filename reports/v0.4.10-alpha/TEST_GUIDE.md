# NIGHT LOOP — 3일 알파 테스트 안내

버전: v0.4.10-alpha / 한국어 / Windows x86_64. 정식 상업 출시본이 아닙니다. 7일 확장과 APK 빌드는 보류합니다.

ZIP을 같은 폴더에 모두 풀고 NightLoop-v0.4.10-alpha.exe를 실행하세요. 별도 Godot 설치는 필요하지 않습니다. SHA256SUMS.txt는 동봉 파일의 확인용 해시이며 자기 자신은 포함하지 않습니다. THIRD_PARTY_NOTICES.txt에 엔진·포함 구성요소 고지를 동봉했습니다.

## 확인 순서

1. 계속하기 → 왼쪽 스틱 또는 A/D·방향키로 이동합니다. 기존 저장이 있으면 이어서 시작합니다. 실제 기록을 삭제하지 마세요.
2. 카페 앞 빈 의자를 탭하거나 E로 관찰합니다. 닫은 후 새 단서 알림, 반복 관찰 후 재확인 알림을 확인합니다.
3. 골목 오른쪽 집에서 귀가 가능 표시를 확인하고 하루를 마칩니다.
4. 2일에 카페 직원 또는 창문 속 직원에게 다가가 F/탭 → 대화를 마쳐 두 잔의 커피에 관한 증언을 얻습니다.
5. T/생각 → 두 근거 선택 → 연결 → 가설 선택. 현재 가설과 수정 이력을 확인합니다.
6. 귀가 후 3일 대화를 확인합니다. 놓친 짧은 대화의 후일담이 먼저 나오면 마친 뒤 다시 이야기합니다. 마지막 귀가 후 엔딩과 회차 기록을 확인합니다.
7. 새로운 3일을 시작하면 현재 단서가 초기화되고 지난 기록은 남는지 확인합니다. 다른 가설로 두 번째 회차를 완료하면 비교할 수 있습니다.
8. 설정에서 안내 숨김/다시 보기, 모션 감소, F11 창/전체 화면을 확인합니다. 중간 저장 후 종료·재실행하여 진행과 설정이 이어지는지 확인합니다.

## 입력

- E 관찰 / F 대화 / T 생각 / N 집 근처 귀가 / Esc 메뉴·닫기 / F11 화면 모드
- Tab·Shift+Tab 선택 이동 / Enter·Space 선택 / Page Up·Down·Home·End 본문 읽기
- 마우스 휠·터치 스크롤, 왼쪽 스틱과 직접 대상 탭. 상세 조작법과 크레딧은 설정에 있습니다.

문제를 기록할 때 버전·재현 순서·기대한 결과·실제 결과·재현 빈도와 화면을 남겨 주세요. 저장 파일·개인 경로·개인정보는 공개 이슈에 그대로 첨부하지 마세요.
